# Git系

## ブランチ

`main` `develop` `feature/***`の3つのブランチをメインに使います。特に`develop`と`main`は直接いじることは避けてください！(featureブランチからのマージのみ)

| ブランチ名 | 意味 |
| --- | --- |
| `main` | リリースを行うブランチです。ここのブランチの内容が本番環境にリリースされます。`develop`ブランチから統合されます。 |
| `develop` | 開発した機能を統合するためのブランチです。`feature/***`ブランチから統合されます。|
| `feature/***` | 実際に開発を行うブランチです。`***`には開発している機能を書きます。　例) 地図を作っている -> `feature/map`|
| `docs` | ドキュメントをいじる時に使います。|
| `hotfix` | `重大なバグが発生したときに早急に治すために使います` |


## コミット

コミットメッセージはあとから読んだときに何をしたかわかるような書き方にしてください！
機能追加などに関しては`〇〇するために〇〇しました`という書き方があると嬉しいです🥇

 
> [!IMPORTANT]
> ❌ Userクラスにageフィールドを追加
> add: 年齢制限機能の実装のためUserクラスにageを追加

接頭辞を採用しています！(見たときに一目で概要がわかるため)コミットメッセージには接頭辞を含めてください！

例) fix: 更新時にユーザが表示されないバグを修正しました

| 接頭辞 | 意味 |
| ----- | ---- |
| docs | ドキュメント関係を追加/変更(`.md`など)|
| add | 新しい機能を追加 |
| update | 既存機能の修正 |
| fix | バグ修正 |
| dele | 機能の削除 |
| refact | リファクタリング |
| style | スタイル変更 |
| rename | ファイル名の変更 |
| move | ファイルの移動 |
| test | テストコード関連 |
